# PhotoCoordinates

一个用于查看和修改 macOS 照片图库 GPS 坐标的原生应用。支持 iCloud 照片、批量坐标转换和地图对照，位置修改直接写入系统照片图库。

## 功能

- 按拍摄时间分组浏览图库，选择系统开放给第三方应用的普通相册或智能相册；可扫描包含相机制造商或型号信息的照片。
- 使用 Shift、Command 或 Control 多选。列表显示文件名、拍摄时间，以及 GPS 和 iCloud 状态图标。
- 在 Apple 地图、OpenStreetMap 或 Google 地图中查看照片位置；搜索地点、输入坐标、双击地图或拖动标记，可设置选中照片的位置。
- 复制照片原始坐标，粘贴到选中的照片；右键照片可复制其坐标或批量粘贴。
- 批量执行 WGS-84 → GCJ-02 或反向转换，显示进度、跳过和失败数量。转换直接写入照片图库；重复执行会再次改变坐标。
- Apple 地图提供大陆 GCJ-02 输入与 WGS-84 原样输入选项；显示选项本身不会修改照片坐标。

## 运行

需要 macOS 14 或更新版本及 Apple Command Line Tools。在项目目录执行：

```sh
./build.sh
open PhotoCoordinates.app
```

首次运行时允许访问照片图库。iCloud 原图可能需要联网下载。程序通过 `PHAssetChangeRequest` 修改图库中的位置，原始文件的 EXIF 字节不一定随之改写，iCloud 同步由系统照片设置控制。

OpenStreetMap 需要联网访问地图瓦片和 Leaflet。Google 地图内嵌显示需要自行提供已启用 Maps JavaScript API 的 API Key；未配置时可在浏览器打开。地图服务会收到当前视图位置相关的网络请求。

## 快捷键

| 按键 | 功能 |
| --- | --- |
| ← / → | 上一张 / 下一张 |
| F / G | 对选中照片执行 WGS-84 → GCJ-02 / GCJ-02 → WGS-84 |
| ⌘⇧C | 复制当前照片的原始坐标 |
| ⌘⇧V | 将剪贴板中的坐标写入选中照片 |

坐标文本格式为 `纬度, 经度`。地图双击或拖针会应用到所有选中的照片。列表右键复制指向照片的坐标；右键粘贴应用到全部选中照片。

## 坐标与数据说明

照片坐标解释和地图输入选项只改变显示；F/G、地图取点、批量设置及粘贴会修改图库。程序无法从普通照片元数据可靠地自动推断坐标系。GCJ-02 转换是近似实现，使用粗略经纬度范围判断，边界和附近地区应人工确认。不同地区的地图服务可能处理坐标不同，建议先用已知位置对照。

列表中的蓝色云朵表示照片的全尺寸静态图像当前需要从 iCloud 下载；这不代表 Live Photo 等全部关联资源的状态，也不能表示云端备份状态。

某些用户自建智能相册可能不会通过系统 API 对第三方应用开放。扫描拍摄设备信息可能需要逐张读取原图，耗时取决于图库和网络。

## 只读测试

```sh
open -n PhotoCoordinates.app --args --read-only
```

只读模式拦截应用的图库写入；可以用于检查列表和地图。构建脚本使用临时本机签名，若要分发给其他电脑，需要自行配置开发者签名与公证。

## 界面语言

支持英语、日语、法语、德语和简体中文，按照 macOS 的首选语言选择；未支持的语言默认使用英语。可在系统设置中调整应用语言，重启应用后生效。
